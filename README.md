# 🎵 뮤지컬 노래방 번호 찾기 앱 **뮤지카** 공유

뮤지컬 넘버를 부르고 싶은데, 매번 노래방 번호 찾느라 시간을 허비하셨나요?  
저도 같은 고민을 하다가, 이 문제를 해결하기 위해 **'뮤지카' 앱**을 제작하게 되었습니다!  
뮤지컬을 사랑하는 분들이 더 쉽고 빠르게 노래방에서 넘버를 즐길 수 있도록 만든 앱이에요. 😊

## ✨ 주요 기능 소개

### 🎭 1. 뮤지컬 넘버 TJ 노래방 번호 리스트 확인  
- 뮤지컬 카테고리를 토글하여 원하는 넘버를 쉽게 찾아볼 수 있어요!

### 📌 2. 오늘 부를 노래 넘버 저장 기능  
- [뮤지컬 번호 리스트] 페이지에서 원하는 곡의 **+ 버튼**을 눌러 저장할 수 있어요.  
- **햄버거 바(≡)** 를 눌러 저장한 목록으로 이동할 수 있어요.  
- **드래그해서** 부를 순서를 자유롭게 조정 가능!  
- **- 버튼**을 눌러 쉽게 삭제할 수도 있어요.

### 🔍 3. 검색 기능  
- 뮤지컬 이름, 넘버 제목, 부른 이(가수) 등으로 검색이 가능해요!  
- 검색어를 입력하지 않으면 **전체 리스트**가 보이고,  
  입력하면 **원하는 곡만 필터링**되어 나와요.
